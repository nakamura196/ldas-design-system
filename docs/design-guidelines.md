# 画面デザイン指針（学術・デジタルアーカイブ向け）

本パッケージ（`@nakamura196/react-ui`）の配色・書体を使って新しい Web アプリや検索画面を設計するときの標準ガイドライン。

配色は **東京大学 Visual Identity Guidelines**（UTokyo ブルー基調）を維持しつつ、レイアウト・余白・情報密度は **[東洋文庫 漢籍データベース](https://kanseki.toyobunko-lab.jp/search?size=n_20_n)** のような端正で一覧性の高い学術データベース UI を基準とする（実装例: `https://dataspace.ldas.jp/catalog/`）。

---

## 1. 避けるべき意匠（「いかにも AI っぽい」SaaS 表現の禁止）

AI に画面設計を任せると、テーマカラーだけ青くしても次のような典型的な SaaS 風テンプレートになりやすい。原則として以下は使わない。

- グラデーション背景、ドット柄オーバーレイ、光るぼかし円（`blur-3xl`）
- グラデーション文字（`bg-clip-text text-transparent`）やガラスモーフィズム（`backdrop-blur` + 半透明ピル）
- 過度な角丸（`rounded-2xl` / `rounded-3xl`）や大きなドロップシャドウ
- 大文字の英語飾りキャプション（例: `01 / DATA SOVEREIGNTY`）や 4 列の飾り統計カード
- 検索結果での「分厚い 2 列カード乱立＋カラフルな丸バッジ過多＋フル幅ボタン」
- 幅を狭く絞りすぎたレイアウト（大画面で左右が大きく余る `max-w-5xl` 以下）

---

## 2. 標準レイアウトと構成

### 全体コンテナと背景・書体

| 項目 | 基準値 |
|---|---|
| コンテナ最大幅 | **`1280px`（`max-w-7xl`）** を標準とする（管理画面等のワイド表は最大 `1600px` 可） |
| ページ背景（Light / Dark） | `#f4f6f8` / `#020617` |
| 面・境界線 | 白 `#ffffff` ＋ 1px 罫線 `#dce3ea`（Dark は `#0f172a` / `#1e293b`） |
| 角丸 | 控えめ（`rounded-md`〜`rounded-lg`、`6px〜8px` 程度） |
| 書体 | `"BIZ UDPGothic", "Hiragino Kaku Gothic ProN", "Hiragino Sans", Meiryo, sans-serif`（または Noto Sans JP） |

### ヘッダーとタイトル帯

1. **グローバルヘッダー**: 濃い UTokyo ブルー単色（`#003d73`、高さ `64px`）に白文字。
   - 左にサイト名（太字テキストのみ、装飾箱を置かない）。
   - 右に横並びのテキストナビ（`ホーム` / `検索・カタログ` 等）＋区切り線＋ログイン・テーマ切替・言語切替。
   - 全ページで同じヘッダー構成に統一する。
2. **サブヘッダー（タイトル帯）**: 検索・トップページの上部に、ヘッダーより一段濃い単色帯（`#002b52`）をフル幅で置き、中央揃えのタイトルと 1 行の簡潔な説明だけを載せる。

### 検索・一覧画面（推奨 4 段構成）

左サイドバーで横幅を削らず、**1 カラム中央揃え（最大幅 `1280px`）** で上から次の 4 段を並べる。

1. **中央検索バー**: 入力欄のみ中央寄せ（`max-w-2xl`）＋右横に `#005096` の「検索」ボタン。
2. **横一列の絞り込みバー**: 白い 1 行枠の中にドロップダウン（カテゴリ／利用条件／提供機関など）を横並びに配置。選択中は青枠ハイライト＋右端に「条件をリセット」。
3. **件数・並び順バー**: 白い 1 行枠の左に `表示中 1 - N 件中 M 件`、右に並び順セレクトボックス。
4. **書誌リスト型の結果一覧**: **1 つの白い枠の中に薄い罫線（`divide-y`）で 1 件 1 行を区切る**。
   - 左側: `#005096` の太字タイトルリンク ＋ 同じ行または直下に提供元・規模などの書誌メタデータ ＋ 1〜2 行の簡潔な説明文。
   - 右側（右揃え）: 上段にカテゴリ・利用条件の端正なテキスト（丸バッジを乱発しない）、下段に識別子（モノスペース控えめグレー）と簡潔なアクションボタン。

## 3. 新規画面を作るときのチェックリスト

- [ ] ヘッダーは単色バー＋白文字で、全ページ共通になっているか
- [ ] コンテナ幅は `max-w-7xl`（1280px）まで広がり、大画面で窮屈に見えないか
- [ ] グラデーション・blur 光球・ガラスモーフィズム・過度な角丸が入っていないか
- [ ] 一覧画面は「カード乱立」ではなく、罫線区切りの書誌リストで一覧性を確保しているか
- [ ] ダークモード・ライトモードの両方でコントラストが保たれているか
